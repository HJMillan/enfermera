# Planilla Enfermera

Aplicación web para registro y gestión de planillas de enfermería.

## Tecnologías

- **React 19**
- **TypeScript**
- **Vite**

## Scripts Disponibles

En el directorio del proyecto puedes ejecutar:

- `npm run dev`: Inicia el servidor de desarrollo local con recarga rápida (HMR).
- `npm run build`: Compila la aplicación para producción en la carpeta `dist`.
- `npm run preview`: Previsualiza localmente la compilación de producción.
- `npm run lint`: Ejecuta ESLint para verificar calidad de código y buenas prácticas.
